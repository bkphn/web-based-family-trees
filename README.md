# Multimedialne Drzewa Genealogiczne

Aplikacja webowa typu Local-First do tworzenia, edycji i wizualizacji drzew genealogicznych.

## Technologie
- React + TypeScript + Vite
- SQLite WASM (baza danych działająca w 100% po stronie przeglądarki)

## Uruchomienie projektu lokalnie
1. Klonowanie repozytorium
2. Instalacja zależności:
   ```bash
   npm install
   ```
3. Uruchamianie serwera deweloperskiego:
    ```bash
    npm run dev
    ```
